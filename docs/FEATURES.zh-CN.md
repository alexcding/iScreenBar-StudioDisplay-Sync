# iScreen Menu 功能清单

> 以 `main` 分支当前已安装版本为准。这是非官方、本地运行的 macOS 菜单栏工具。

## 1. 菜单栏与运行状态

- 单击菜单栏图标打开系统菜单：顶部为灯光面板，下方为原生子菜单与“退出”（⌘Q）。
- 单色图标：中间圆环常亮，周围 8 条光芒按亮度点亮；灯关闭或未连接时光芒变淡。
- USB 连接、Studio Display 识别或灯体电源指令异常时，图标右下角显示小圆点，面板顶部显示“同步异常”。
- 悬停图标显示 iScreenBar 当前亮度和色温。
- 打开菜单时主动读取灯体状态；菜单展开期间同步与状态回读不中断。
- 通过用户级 LaunchAgent 登录后自动运行，无需管理员权限；从菜单退出后保持退出，仅异常退出时自动重启。

## 2. iScreenBar 基础控制

- **灯光开关**：面板右上角圆形按钮直接开启或关闭 iScreenBar。
- **亮度调节**：1%--100%，可从面板滑块调节。
- **色温调节**：2700K--6500K，按 100K 档位调节。
- **状态回读**：读取开关、亮度、主灯/背灯色温、自动感光、入座检测和视频模式状态。
- **手动操作兼容**：灯体上的物理按键改变状态后，工具会重新读取并刷新界面。
- **灯关闭时调节**：拖动亮度/色温、切换自动感光或应用预设时先开灯，约 0.5 秒后再写入；等待期间同类调整只保留最新一次。环境光规则关灯期间不会因此开灯。

## 3. Studio Display 熄屏同步

- Studio Display 熄屏或进入休眠时，自动关闭 iScreenBar。
- Studio Display 唤醒时，如果灯是由本工具关闭的，则自动恢复开灯。
- 熄屏期间电源同步具有最高优先级：灯体自动感光、入座检测或其他逻辑不得重新点亮灯。
- “熄屏同步”按钮可单独开启或关闭该功能。

## 4. iScreenBar 亮度跟随 Studio Display

- “亮度跟随”开启时，记录 iScreenBar 与 Studio Display 当前亮度差。
- 之后调节 Studio Display 亮度，iScreenBar 按固定差值同步变化。
- 保留 iScreenBar 1% 的最低亮度限制。
- 关闭后灯体保持当前亮度，不恢复到旧数值。
- 灯体自动感光与该功能互斥：开启其中一个时，自动关闭另一个，避免两个亮度源同时控制灯。

## 5. 灯体自动感光

- 可在菜单面板中开启或关闭 iScreenBar 自带的环境光传感器。
- 开启时使用灯体官方自动感光状态；关闭时写入当前手动亮度以退出自动模式。
- 界面显示实际灯体回读状态，包含短暂的指令确认过渡。
- 已知灯体固件特性：物理自动感光键能进入或重新标定自动模式，但不一定能稳定退出；菜单面板可执行可验证的关闭流程。

## 6. Studio Display 环境光标定与自动开关灯

- 直接读取 Studio Display 环境光传感器，不使用灯体传感器作为这组规则的数据源。
- 使用最近 10 秒样本的中位数作为“环境响应分数”，降低瞬时光线波动。
- **明亮关灯点**：点击时采集当前数值；高于该值并持续 30 秒后关灯。
- **昏暗开灯点**：点击时采集当前数值；低于该值并持续约 30 秒后开灯。
- 环境关灯后还有约 45 秒的渐进回开路径，允许小幅波动，避免反复闪烁或长时间不开灯。
- 两个标定点可分别存在，不要求同时设置。
- 标定按钮只在采集成功时短暂点亮，旁边保留已保存数值。
- 独立的启用开关决定是否执行已保存的阈值；关闭不会删除标定数值。
- 如果开灯点高于或等于关灯点，界面会提示阈值重叠风险。
- 环境关灯锁定后，灯体自动感光和入座检测不能重新点亮灯。
- 如果关灯前入座检测处于开启状态，会临时暂停；环境关灯锁定解除后自动恢复。
- 熄屏同步优先级高于环境光规则：屏幕已熄灭时，环境变暗也不会开灯。

## 7. 入座/离席检测

- 可在面板中开启或关闭灯体入座检测。
- 离席时间支持 3、5、10 分钟。
- 侦测灵敏度支持低、中、高三档。
- 设置在灯体支持时直接下发；下发失败时保留本地选项并记录日志。
- 会与环境关灯锁定协同，避免“关灯后人一动又点亮”。

## 8. 视频模式

- 可从面板开启或关闭 iScreenBar 视频模式。
- 视频模式状态会从灯体回读，并可作为灯光模式预设的一部分保存。

## 9. 自动色温

- “自动色温”按时间平滑调整灯体色温。
- 00:00--06:00：3000K。
- 06:00--10:00：从 3000K 逐步过渡到 5500K。
- 10:00--16:00：5500K。
- 16:00--21:00：从 5500K 逐步过渡到 3500K。
- 21:00--24:00：从 3500K 逐步过渡到 3000K。
- 以 50K 为内部过渡步进，最多每分钟向灯体写入一次。
- 灯关闭或 Studio Display 熄屏时不写入色温。
- 关闭自动色温后保持当前色温。

## 10. 灯光模式预设

- 内置“我的最爱”默认值：47% / 5500K / 视频模式关闭。
- 内置“夜间工作”：30% / 4000K / 视频模式关闭。
- 内置“睡前放松”：20% / 3000K / 视频模式关闭。
- 可把当前亮度、色温和视频模式保存为自定义场景。
- “模式中心”用列表展示可用模式，支持快速应用。
- 应用预设时自动开灯、写入亮度和色温、设置视频模式，并关闭 iScreenBar 亮度跟随。
- 可把当前灯光模式绑定到指定 macOS 应用；前台应用切换时自动应用对应模式。

## 11. USB 断开、重连与容错

- 每 2 秒检查一次 iScreenBar USB HID 连接。
- 灯被拔出、断电或 HID 指令失效时，图标显示异常圆点并写入日志。
- 灯重新插入后重建 HID Manager、重新读取状态，并恢复熄屏同步和亮度跟随锁定。
- Studio Display 断开时程序继续驻留，连回后自动重建显示监听和环境光传感器连接。
- 所有关键状态和异常写入 `~/Library/Logs/iScreenBarStudioSync.log`。

## 12. 界面与交互

- 原生 AppKit 系统菜单，不需要 Dock 图标，自动适配浅色/深色模式。
- 两列开关卡片：圆形 SF Symbols 图标开启时为强调色，部分开关开启时显示简短说明。
- 亮度滑块为白色填充，色温滑块为暖到冷渐变加白色标记；点按轨道任意位置即可跳转，松开时写入灯体。
- 自动感光开启时亮度滑块置灰，自动色温开启时色温滑块置灰；灯离线时相关控件置灰。

## 13. 本地存储、隐私与安装

- 所有开关、阈值、预设和应用绑定存在本机 `UserDefaults`。
- 不需要账户、云端服务、网络 API 或数据分析。
- 安装脚本本地编译、临时签名、安装到 `~/Applications`，并创建用户级 LaunchAgent。
- 卸载脚本停止服务，并将安装版和 LaunchAgent 移入废纸篓；日志默认保留供排查。

## 14. 实现边界与风险提示

- 已在 Apple Silicon Mac、macOS 26、Apple Studio Display 和 BenQ iScreenBar `VID 0x04A5 / PID 0x2501` 上验证。
- iScreenBar 控制使用设备特定的 33 字节 HID 报文，其他型号不保证兼容。
- Studio Display 亮度读取使用 macOS 私有 DisplayServices 接口，系统升级后需要真机回归验证。
- Studio Display 按 Apple 厂商 ID 0x0610 与产品 ID 0xAE46 / 0xAE3A 识别，未收录的型号按屏幕名称 “Studio Display” 识别。
- 灯体自动感光和入座检测的部分细节受灯体固件版本影响。

## 15. 功能优先级

1. Studio Display 熄屏同步：屏幕熄灭时灯保持关闭。
2. Studio Display 环境关灯锁定：达到明亮阈值后抑制入座检测、自动感光和手动调节重新开灯。
3. 灯体自动感光与 iScreenBar 亮度跟随互斥。

## 16. 与明基官方 iScreenBar App 的差异

> 对照依据为明基 iScreenBar 官方产品页、快速入门指南和公开功能说明。官方 App 会随地区和版本更新，以下比较以 2026 年 8 月公开资料及本机官方 App 为准。

### 16.1 双方都具备的功能

| 功能 | 明基官方 App | 本工具 | 主要区别 |
| --- | --- | --- | --- |
| 灯光开关 | 支持 | 支持 | 本工具增加 USB 离线异常提示和重连恢复。 |
| 亮度和色温 | 支持 | 支持 | 官方宣传 0--100% 无级亮度、2700K--6500K；本工具按灯体 HID 可验证档位写入。 |
| 自动感光 | 支持 | 支持 | 两者都调用灯体环境光传感器；本工具额外处理与亮度跟随互斥。 |
| 入座检测 | 支持 | 支持 | 官方使用 24GHz 毫米波传感器并允许调整侦测范围；本工具提供离席时间和灵敏度控制。 |
| 视频模式 | 支持 | 支持 | 官方可结合 iMac 相机自动启用；本工具目前以手动开关和模式预设为主。 |
| 灯光模式 | 支持 | 支持 | 两者都可保存亮度、色温等组合。 |
| 按应用绑定模式 | 支持 | 支持 | 两者都能在前台应用变化时应用对应灯光模式。 |
| 随显示器开关灯 | 支持 | 支持 | 官方针对兼容 iMac；本工具补齐 Studio Display 独立熄屏场景。 |

### 16.2 本工具相对官方 App 增加的功能

- **Studio Display 正式适配**：官方公开兼容范围是 2021 年及以后 iMac，不包含 Apple Studio Display；本工具专门监听 Studio Display 的休眠、熄屏、唤醒和断开重连。
- **Studio Display 亮度联动灯体**：保持灯与显示器当前亮度差，调节 Studio Display 时同步改变 iScreenBar。
- **Studio Display 环境光阈值控制**：可分别采集“明亮关灯点”和“昏暗开灯点”，使用中位数、持续时间和优先级规则自动开关灯。
- **自动色温**：按一天中的时间在 3000K--5500K 之间平滑变化，而非只依赖手动档位或固定模式。
- **可见的健康状态**：菜单栏图标用光芒数量表示亮度，异常时显示提示圆点，并在悬停时显示亮度与色温。
- **更明确的规则优先级**：熄屏、环境关灯、入座检测、自动感光和亮度跟随之间有显式互斥及恢复规则。
- **USB 容错与日志**：灯体拔插后自动重建 HID Manager，保留本地日志用于排查。
- **本地化与可审计**：配置只存本机，没有账号、云端或数据分析；源码以 MIT 许可证公开。

### 16.3 官方 App 当前更有优势的部分

- **官方签名、发布和固件适配**：官方 App 由明基维护，对固件升级、区域版本和灯体协议变化具有正式支持。
- **iMac 原生兼容**：官方针对 2021 年及以后 iMac 的硬件、供电、相机和唤醒流程设计，兼容边界更明确。
- **相机自动视频模式**：官方资料说明通过 iMac USB-C 连接时可自动激活相机模式；本工具尚未实现可靠的摄像头占用自动检测。
- **官方灯体记忆语义**：灯体自身保存的“我的最爱/记忆”由固件管理；本工具的模式预设主要保存在 Mac `UserDefaults`，不是同一种硬件记忆。
- **交互完成度和支持渠道**：官方 App 的引导、升级、签名、公证、客服和保修支持更完整。
- **系统升级风险更低**：本工具读取 Studio Display 亮度依赖 macOS 私有接口，需要在系统升级后重新验证。

### 16.4 尚未完全对齐或需要继续验证

- 摄像头启用时自动切换视频模式。
- 官方 App 与灯体“我的最爱”硬件记忆的读取、覆盖和调用协议。
- 官方入座检测全部时间档位及不同固件版本下的灵敏度映射。
- 官方模式绑定在应用退出、全屏、多个 Space 和多用户会话下的精确行为。
- Developer ID 正式签名、公证、自动更新和面向普通用户的一键安装体验。

### 16.5 一句话定位

**官方 App 是面向兼容 iMac 的完整原厂控制软件；本工具是在保留主要灯控能力的基础上，为 Studio Display 补齐熄屏同步、亮度联动、环境光规则及故障恢复。**
