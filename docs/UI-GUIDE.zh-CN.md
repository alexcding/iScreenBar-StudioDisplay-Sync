# iScreen Menu 界面使用指南

本页按菜单从上到下说明。点按菜单栏图标打开菜单；点按菜单外任意位置或按 Esc 关闭。

<img src="images/menu.png" alt="iScreen Menu 菜单面板" width="345">

## 1. 顶部状态与开关

左侧显示 “iScreenBar” 和连接状态：绿色圆点表示已连接，橙色表示同步异常（通常是未识别到 Studio Display），灰色表示灯未连接。灯打开时状态行同时显示当前亮度和色温。

右侧圆形按钮开关灯，蓝色表示灯已打开。

## 2. 亮度与色温

- **亮度**：白色填充越长越亮。灯的 1% 为控制范围下限，不代表完全熄灭；完全关闭请点右上角按钮。
- **色温**：左暖右冷，白色标记表示当前色温。

松开滑块时才写入灯体。灯关闭时拖动滑块会先开灯再调节。自动感光开启时亮度滑块置灰（亮度由灯体传感器控制）；自动色温开启时色温滑块置灰。

## 3. 开关

圆形图标为蓝色表示开启，部分开关在开启时显示简短说明。悬停可查看完整说明。

| 开关 | 用法 |
| --- | --- |
| 自动感光 | 由灯体传感器调节亮度；与亮度跟随互斥 |
| 自动色温 | 根据本地时间逐渐调整色温，并不是测量环境色温 |
| 入座检测 | 使用灯体检测离席后关灯；时间和灵敏度在“入座检测设置”中调整 |
| 视频模式 | 视频会议补光模式 |
| 亮度跟随 | 先把灯和 Studio Display 调到舒适亮度，再开启以记录差值 |
| 熄屏同步 | Studio Display 熄屏后关灯，唤醒后按规则恢复 |

## 4. 入座检测设置

子菜单中选择离席时间（3/5/10 分钟）和侦测灵敏度（低/中/高）。环境关灯或熄屏期间，软件会临时暂停入座检测，解除后按之前状态恢复。

## 5. 环境光标定

在你认为足够明亮时选择“记录当前光线为关灯点”，在需要补光时选择“记录当前光线为开灯点”，分别记录 Studio Display 传感器数值。“按环境光自动开关灯”用于重复使用已存阈值，无需每天重新采集。子菜单底部显示当前环境数值和标定状态。

“当前环境”是 Studio Display 传感器经滤波后的相对数值，不是校准照度计。关灯与快速开灯约需持续 30 秒，渐进回开约 45 秒；中间范围可能保持原状态。熄屏同步优先，环境变暗不能在显示器熄屏时把灯唤起。

## 6. 灯光预设

保存亮度、色温和视频模式；“模式中心设置…”可新增场景并绑定前台应用。它与灯体自己的硬件记忆不同。
